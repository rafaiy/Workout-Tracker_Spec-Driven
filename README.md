# Workout-Tracker_Spec-Driven
Gym Workout Planner &amp; Tracker Web Application. An application where users can explore predefined gym exercises, create personalized workout plans, organize exercises into workout splits, track daily gym sessions, and monitor fitness progress.

# GymFlow

Mobile-first GymFlow MVP with a React/TypeScript frontend and Express/TypeScript API.

## Run

```bash
npm install --prefix backend
npm install --prefix frontend
npm run dev
```

- Frontend: http://localhost:5173
- Backend: http://localhost:4000
- Health: http://localhost:4000/api/v1/health

## Build and test

```bash
npm run build
npm test
```

The MVP API uses a demo in-memory data store for immediate validation. Production persistence can be added with PostgreSQL migrations described in the implementation plan.
